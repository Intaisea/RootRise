USB Serial uses Web Serial in a supported desktop Chromium browser over HTTPS or localhost. Bluetooth LE requires BLE UART firmware; Bluetooth Classic SPP is not supported by webpages. The Android APK needs a native USB serial bridge.

Expected device name: RootRise-ESP32
Line protocol: DATA,temp,humidity,pump,seconds[,soil,litres,lat,lon] · Commands: GET, PUMP,0/1, RUN,seconds

Pump control

OFFLINE
The firmware must map PUMP,1 / PUMP,0 to the relay GPIO. Blue status appears only after the ESP32 reports pump=1 in a DATA line. If Terminal works but the relay does not switch, the firmware relay pin/output logic must be checked.

Smart watering
Enable watering when soil moisture drops below your chosen level. Requires a live soil sensor value from the ESP32.

The ESP32 must send calibrated soil moisture as DATA field 6 (0–100%) or SOIL,percent, and execute RUN commands on its relay. Automation stops retriggering until soil rises 5 points above the threshold.
